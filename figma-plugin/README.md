# Voronoi Shatter Figma Plugin

Load the plugin locally in Figma Desktop:

1. Build the Voronoi Shatter UI bundle for the plugin so `ui.html` is available alongside `manifest.json`.
2. Open **Figma Desktop** and go to **Plugins -> Development -> Import plugin from manifest...**.
3. Select `figma-plugin/manifest.json` from this repository, then run **Plugins -> Development -> Voronoi Shatter**.
